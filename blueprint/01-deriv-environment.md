# Deriv Synthetic Indices — The Trading Environment

---

## What Are Synthetic Indices?

Market prices generated by a **Cryptographically Secure Random Number Generator (CSRNG)**, audited for fairness. Designed to mimic real-world market volatility patterns.

### Key Characteristics

- **News-proof** — unaffected by NFP, interest rates, geopolitics
- **24/7/365** — no weekends, no holidays, no market close
- **Pattern-following** — the algorithm is programmed to produce recognizable technical patterns
- **House edge** — long-term mathematical advantage built into the system

## Contract Types Available

- **Rise/Fall** — predict if price will be higher/lower after N ticks
- **Touch/No Touch** — price reaches a target barrier
- **Higher/Lower** — price ends higher/lower than a barrier
- **Even/Odd** — last digit of tick is even or odd
- **Over/Under** — last digit is over/under a number
- **Digit Match/Differ** — last digit matches/differs from prediction

## Tick Resolution

- Standard indices: ~2 ticks/second
- 1Hz indices: exactly 1 tick/second
- Tick data is the raw material — OHLC candles are derived from ticks
- **M1, M5, M15, H1, H4, D1** candle timeframes all available

## API Access

- **WebSocket API** — real-time tick streaming, trade execution (`ws.deriv.com`)
- **REST API** — account management, history
- **MT5** — MetaTrader 5 support for standard indices
- **DBot** — Deriv's visual bot builder (limited, not for our use case)

### API Requirements

1. Register app at `api.deriv.com` → get `app_id`
2. Generate API token from account settings
3. WebSocket connection for live trading
4. Rate limits exist — need to respect them

## Why This Matters for Our Bot

- **No fundamental analysis needed** — pure technical + statistical approach
- **24/7 operation** — bot runs continuously, no market gaps
- **Predictable volatility profiles** — each index has known volatility characteristics
- **Tick-level data** — can build any timeframe from raw ticks
- **House edge exists** — we need an edge that overcomes the built-in disadvantage
