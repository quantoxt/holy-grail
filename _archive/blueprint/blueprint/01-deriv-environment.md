# Deriv Synthetic Indices — The Trading Environment

---

## What Are Synthetic Indices?

Market prices generated by a **Cryptographically Secure Random Number Generator (CSRNG)**, audited for fairness. Designed to mimic real-world market volatility patterns.

### Key Characteristics

- **News-proof** — unaffected by NFP, interest rates, geopolitics
- **24/7/365** — no weekends, no holidays, no market close
- **Pattern-following** — the algorithm is programmed to produce recognizable technical patterns
- **House edge** — long-term mathematical advantage built into the system

## Contract Types Available

- **Rise/Fall** — predict if price will be higher/lower after N ticks
- **Touch/No Touch** — price reaches a target barrier
- **Higher/Lower** — price ends higher/lower than a barrier
- **Even/Odd** — last digit of tick is even or odd
- **Over/Under** — last digit is over/under a number
- **Digit Match/Differ** — last digit matches/differs from prediction

## Tick Resolution

- Standard indices: ~2 ticks/second
- 1Hz indices: exactly 1 tick/second
- Tick data is the raw material — OHLC candles are derived from ticks
- **M1, M5, M15, H1, H4, D1** candle timeframes all available

## API Access

> **⚠ Updated 2026-08-02 — Deriv migrated to a new PAT/Options API.** The legacy
> `wss://ws.derivws.com` + `app_id=1089` + `{authorize: <token>}` flow is **dead**
> for current PAT tokens (returns "The token is invalid"). See memory `deriv-new-api-auth`.

- **Options REST API** — `https://api.derivws.com/trading/v1/options/*` — account list, OTP minting.
- **Options WebSocket API** — `wss://api.derivws.com/trading/v1/options/ws/{public|demo|real}` — tick streaming + trade execution. Authenticated via a short-lived OTP embedded in the URL.
- **MT5** — MetaTrader 5 still exists for standard indices but is **not used** (we connect directly).

### API Requirements (current flow)

1. Register an app at **[developer.deriv.com](https://developer.deriv.com)** → get an **alphanumeric app identifier** (e.g. `340bsoJb…`).
2. Generate a **PAT (Personal Access Token)** at **home.deriv.com → Security & Limits → API token** (scopes: Read now, +Trade for Phase 1).
3. `GET /options/accounts` → discover your account id (Demo=`DOT…`, Real=`ROT…`).
4. `POST /options/accounts/{accountId}/otp` with headers `Deriv-App-ID` + `Authorization: Bearer <PAT>` → returns an authenticated `wss://…?otp=…` URL.
5. Connect to that URL — the OTP authenticates the session; **no separate `authorize` message**. OTPs are short-lived, so mint a fresh one per connection.
6. Rate limits exist — respect them (the collector paginates + throttles).

| Item | Where to Get It | Used For |

### How They're Used

```
.env file:
DERIV_APP_IDENTIFIER=340bsoJb…        # from developer.deriv.com (alphanumeric)
DERIV_API_TOKEN=pat_…                  # PAT from home.deriv.com → Security & Limits → API token
DERIV_ACCOUNT_ID=DOT92639997           # from GET /options/accounts (Demo=DOT, Real=ROT)
DERIV_API_BASE=https://api.derivws.com/trading/v1/options

TELEGRAM_BOT_TOKEN=your_bot_token
TELEGRAM_CHAT_ID=your_chat_id

SUPABASE_URL=http://localhost:54321
SUPABASE_ANON_KEY=your_anon_key
```

### Security Notes
- **Never commit `.env` to git** — `.env.example` with placeholder values only
- API tokens are sensitive — treat like passwords
- Deriv demo API tokens have limited permissions (trade only on demo account)
- Live API tokens should be generated with minimal required scopes

## No MT5 Needed

Deriv synthetics are available on MT5, but MT5 is **not used in this project.** The bot connects directly to Deriv's WebSocket API — same data source, no middleman. MT5 would add an unnecessary MQL5 ↔ Python bridge with no benefit.
